---
title: InProduct
description: Small, composable tools that live inside your application.
---

InProduct puts reusable building blocks in the application that owns its data and workflows.
This is an early scaffold: the published library currently contains **one utility, `slugify`**.
Feature flags, audit logs, notifications, payments and commerce APIs are not implemented.

## Start small

- [Install the package](/docs/installation) and call it from your own code.
- [Integrate with a backend](/docs/backend) without a hosted service or API key.
- [Run MyShop locally](/docs/myshop) to see a storefront and a tiny product editor.

The library is `@mp-lb/inproduct`. The repository's `@mp-lb/inproduct-backend` package
is a private example health service, not the npm package to install.
